# ia-para-pequena-sempresas
Projeto desenvolvido para a DIO utilizando o NotebookLM para investigar aplicações de inteligência Artificial em pequenas empresas.
IA para pequenas empresas: do problema à solução.
Este projeto foi desenvilvido como parte de uma atividade da DIO utiliza o NotebookLM.
O objetivo é investigar como a inteligência Artificial pode ser aplicada em pequenas empresas para melhora produtividade, atendimentoao cliente e a geraçaõ de oportunidade de vendas.
OBJETITIVO:
Analisar, a partir de fontes confiáveis, como ferramenta de Inteligência Artifiacial podem contribuir para a transformação digital de pequenos negócios.
# PROBLEMA:
Pequenas empresas frequentemente enfrentam dificuldades relacionadas à produtividade, marketing, atendimento, geração de leads e análise de informações.
Diante do cenário, surge a seguinte pergunta:
**Como a Inteligência Artificial pode ajudar pequenas empresas a melhorar seu processos, fortalecer o marketing e gerar mais oportunidades de vendas?
